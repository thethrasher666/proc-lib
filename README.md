# Process Library

This is a C++ library for running and managing processes in a cross-platform manner. It provides a simple and consistent interface for creating, controlling, and communicating with processes on different operating systems.

## Documentation

Documentation can be found online on [GitHub Pages](https://thethrasher666.github.io/proc-lib/).
